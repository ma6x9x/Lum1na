# App logo

The initial app screen now includes a native SwiftUI recreation of the supplied Lum1na visual direction: a dark cosmic background, purple/cyan ring, and luminous four-point sparkle.

The supplied image is not committed as a binary asset because GitHub file writes here preserve text source files only. To use the exact artwork, export it as an app icon and add the generated 1024px icon set to `Assets.xcassets` in Xcode. Keep the full artwork for in-app branding and use a simplified, opaque-safe crop for the home-screen icon.
